# HallPass

One API key for Claude, GPT, Codex, and 130+ AI models — **[hallpassai.com](https://hallpassai.com)**.

## Quick start

Generate a pairing code on **[app.hallpassai.com/start.html#connect](https://app.hallpassai.com/start.html#connect)**, then run:

```bash
npx hallpassai@latest HP-XXXX-XXXX
```

Supported out of the box: **Claude Code**, **Codex CLI**, **OpenCode**, **GitHub Copilot CLI**, and **Cursor**.

- CLI & connectors: **[hallpassai/hallpassai](https://github.com/hallpassai/hallpassai)** ([`hallpassai` on npm](https://www.npmjs.com/package/hallpassai))
- Support: `support@hallpassai.com`
